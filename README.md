# Gary.R
USER GUIDE – Bean There, Read That

Overview
Bean There, Read That is a simple Python console application that allows customers to browse coffee and book products, add items to an order, review their selections, apply staff discounts, and save the final order to a TXT file.

How to Use the Application

1. Starting the Program
Run the Python file using:
python app.py
(Replace app.py with your actual filename.)

When the program starts, you will see a numbered menu. Type the number of the option you want to use.

2. View Products
Select option 1.
This displays all available coffee and book items along with their prices.

3. View Product Details
Select option 2.
You will be asked to enter a product ID.
Type the number shown in the product list to view the name, price, and description.

4. Add a Product to Your Order
Select option 3.
Enter the product ID.
If the ID is valid, the item is added to your order.

5. Review Your Order
Select option 4.
This shows all items currently in your order and displays the total cost.

6. Apply Staff Discount
Select option 5.
A 10% discount is applied to the total.
The program shows:
- Original total
- Discount amount
- Final total after discount

7. Save Order to TXT File
Select option 6.
The program creates a file named order.txt containing:
- All ordered items
- Their prices
- The total cost

8. Exit the Program
Select option 7 to close the application.

Summary
The application is menu-driven and easy to use. You choose options by typing numbers, and the program guides you through each step. Customers can browse and order items, while employees can apply discounts and save orders to a TXT file.
